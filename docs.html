Sahayak — AI Browser Assistant

Your browser AI co-pilot — reads, explains, sees, and acts on web pages with your explicit approval.

Chrome Manifest V3 Release v1.0.0 MIT License

Sahayak is a Chrome Extension (Manifest V3) that lives in your browser's side panel. Built with Google's Gemini 2.5 Flash and resilient failover via Groq (Llama-3.1-8b), Sahayak digests dense articles, answers visual questions from screenshots, manages personal profiles for one-click form completion, and executes browser actions step-by-step under strict deterministic safety rails.

✨ Complete Feature Breakdown

Phase 1: The Reader & Explainer

  • Structured 3-Part Brief: One-click article extraction powered by Mozilla Readability. Delivers a 💡 TL;DR single-sentence core insight, 📌 5 Key Takeaways, and 🎯 Next Steps with paywall/teaser detection.
  • Text Explanation: Paste or select text on any page for an instant, plain-language explanation with 1-click clipboard copy.
  • Bilingual English & Hinglish: Seamlessly switch between standard English and Roman-script Hinglish (hi-en) at any time.
  • Right-Click Context Menu: Highlight text anywhere to "Explain", "Summarise", or "Translate" directly from the native Chrome context menu.

Phase 2: The Chat & Vision Engine

  • In-Page Grounded Chat: Ask questions grounded strictly in live DOM content with session memory and quick follow-up chips.
  • Multimodal Screenshot Q&A: Capture full viewport or interactive cropped canvas regions. Gemini Flash visually inspects charts, flowcharts, tables, and infographics.
  • Free-Tier Resilience & Fallback: Exponential backoff with jitter on HTTP 429 quota exhaustion, seamlessly failing over to Groq (llama-3.1-8b-instant) for text queries.

Phase 3: The Supervised Agent ("The Hands")

  • Interactive Element Scanner: Scans clickable links, buttons, inputs, and dropdowns into an accessibility-aligned actionMap.
  • Numbered Visual Badges: Overlays high-contrast badges (#1, #2, #3) directly over interactive page elements.
  • Supervised Approval Loop: Proposes one action at a time via an ActionCard. Requires human approval before executing. Includes a Dry-Run Mode checkbox and persistent [STOP] button.
  • Synthetic Event Dispatcher: Dispatches native descriptor setters and full event sequences (pointerdown, mousedown, input, change) compatible with React, Vue, and Angular forms.

Phase 4: Memory, Custom Skills & Safety Rails

  • Local Profile Memory: Store personal, academic, and professional info directly in chrome.storage.local for instant 1-click form filling.
  • One-Click Saved Skills: Ships with built-in skills (Exam Notes, Explain in Hinglish, Reply Politely, Fill Form) and custom skill creation with template variables ({{selectedText}}, {{profile.fullName}}).
  • Deterministic Safety Rails: Hardcoded domain blocklists (banking, UPI, crypto, government ID), credential field blocklists (passwords, OTPs, PINs, CVVs), and consequential action double-confirmations.

🚀 Quickstart Installation

Option A: Install from Release ZIP (Recommended)

  1. Download the latest sahayak-v1.0.0.zip from Releases.
  2. Extract the archive into a folder on your computer.
  3. Open Chrome (or Brave, Edge, Arc) and go to chrome://extensions.
  4. Toggle on Developer mode in the top-right corner.
  5. Click Load unpacked and select the unzipped directory.
  6. Pin Sahayak to your toolbar for easy 1-click access.

Option B: Clone from Source

git clone https://github.com/your-username/sahayak.git
cd sahayak

Then load the folder directly via chrome://extensions using Load unpacked.

⚙️ Configuration & API Keys

  1. Open the Sahayak side panel by clicking the toolbar icon.
  2. Click the ⚙️ Settings button in the top right.
  3. Primary Model (Gemini): Obtain a free API key from Google AI Studio and paste it into the Gemini API Key field.
  4. Backup Model (Optional Groq): Obtain a key from Groq Console and paste it into the Groq field.
  5. Click 💾 Save Settings.
🔒 Local Privacy Guarantee: Your API keys and profile information are stored exclusively in your browser's local chrome.storage.local. They are never sent through any intermediary proxy servers.

📖 Usage Guide & Examples

1. Summarising Articles

Open any article, click the Summary tab, and hit ⚡ Summarise This Page to receive the structured 3-part brief.

2. Grounded Chat with Webpages

Switch to the Chat tab and ask specific questions (e.g. "What pricing plans are described on this page?"). Responses are grounded strictly in live DOM context.

3. Visual Screenshot Q&A

Switch to the Vision tab. Choose Full Viewport or Select Area to crop a chart, then ask questions about the visual data.

4. Running the Supervised Agent

On any form or multi-step page, switch to the Agent tab. Enter your goal (e.g. "Fill in the contact form using my profile details"), review each proposed action, and click ✓ Approve.

5. Managing Saved Skills

Use the Skills tab to run pre-packaged routines like 📝 Exam Notes, or create reusable custom skills using {{selectedText}} and {{profile.fullName}} variables.

🛡️ Deterministic Safety Principles

Non-Negotiable Code Guardrails: Unlike prompt-based safety that LLMs can ignore, Sahayak enforces hard deterministic code rules before any action is proposed or dispatched.
  • Domain Blocklist: Completely blocks reading and automation on banking (SBI, HDFC, Chase), payments (PayPal, Stripe, Razorpay), crypto (Binance, Coinbase), and government identity portals (UIDAI, IncomeTax).
  • Field Blocklist: Prevents typing into fields with type password or names matching otp, pin, cvv, card, ssn, or aadhaar.
  • Consequential Action Gate: Actions matching submit, pay, purchase, or delete require an explicit manual checkbox confirmation.
  • Emergency Stop: The persistent red [STOP] button terminates execution immediately and clears all on-screen badges.

🧪 Development & Packaging

Sahayak uses pure Node.js without npm build tools or compilation steps.

Run Automated Test Suite:

node scripts/run-tests.js
# or
npm test

Build Release ZIP:

node scripts/build-zip.js
# or
npm run build:zip

Produces sahayak-v1.0.0.zip containing only the runtime extension files and excluding tests, docs, and git files.
