🛡️ Deterministic Safety Rails

Unlike probabilistic AI wrappers, Sahayak enforces hard deterministic code rules before any action is suggested or executed.

🛑 Blocked Sensitive Domains

Zero action or content transmission on netbanking, payment gateways, UPI portals, cryptocurrency exchanges, and government ID services.

🔒 Blocked Credential Fields

Hardcoded exclusion of passwords, PINs, OTPs, CVVs, card numbers, Aadhaar numbers, and SSNs. The agent physically cannot type into them.

⚠️ Consequential Action Gate

Submitting, paying, purchasing, deleting, or transferring triggers a high-visibility red warning banner requiring an explicit confirmation checkbox.

Quickstart Installation

Get up and running in under 2 minutes without building or compiling.

1

Download Release ZIP

Download the latest sahayak-v1.0.0.zip from GitHub Releases and extract it to a directory on your machine.

2

Open Chrome Extensions

Navigate to chrome://extensions in your Chromium browser (Chrome, Brave, Edge, Arc) and enable Developer mode in the top-right corner.

3

Load Unpacked Extension

Click the Load unpacked button and select the extracted folder. Pin Sahayak to your browser toolbar for quick access.

4

Configure Free Gemini API Key

Click the extension icon to open the side panel, click ⚙️ Settings, and paste your free key from Google AI Studio. Optionally add a Groq key for instant backup failover.
